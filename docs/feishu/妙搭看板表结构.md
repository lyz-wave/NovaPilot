# 妙搭看板表结构(基于 NovaPilot 同步的多维表格)

妙搭没有对外 API,它是在多维表格之上拖拽搭建的无代码应用。NovaPilot 已把两张表自动写入
你的 Bitable(FEISHU_BITABLE_APP_TOKEN 对应的多维表格),妙搭按下面配方搭建即可。

## 表一:决策卡(系统自动创建/同步,字段如下)

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 卡片ID | 文本 | 主键,幂等 upsert |
| 标题 | 文本 | 决策卡标题 |
| 状态 | 文本 | formal / provisional / needs-conditions / expert-review |
| 风险 | 文本 | low / medium / high |
| 客户目标 | 文本 | 客户原始目标 |
| 证据引用 | 文本 | 引用 ID 分号连接 |
| 更新时间 | 文本 | ISO 时间 |

## 表二:质量事件(系统自动创建/同步)

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| 事件ID | 文本 | 主键 |
| 门禁 | 文本 | 引用有效率等 |
| 数值 | 文本 | 注入值 |
| 责任人 | 文本 | 责任组 |
| 状态 | 文本 | OPEN / 已关闭 |
| 关闭证据 | 文本 | 人工填写 |
| 是否模拟 | 复选 | 展示层注入标记 |

## 妙搭视图配方(10 分钟搭完)

1. 新建妙搭应用 → 数据源选上面两张表。
2. 首页视图「今日待办」:筛选 状态=OPEN 的质量事件 + 状态=expert-review 的决策卡,卡片列表。
3. 看板视图「专家工单」:按 风险 分组拖拽(高/中/低列)。
4. 统计视图「门禁健康」:质量事件表按 门禁 分组计数,显示 OPEN 数量。
5. 明细视图:决策卡单行详情(客户目标/证据引用全宽显示)。
6. 发布到工作台或嵌入群聊,专家直接在飞书里处理。

这样「AI 生成 → 多维表格沉淀 → 妙搭呈现 → 专家在飞书里处理」的闭环就完整了。
